# ВедиБюджет — Backend API

Backend-часть мобильного приложения «ВедиБюджет» для учёта личных финансов.

## Технологический стек

- Python
- FastAPI — создание REST API
- SQLite — хранение данных
- SQLAlchemy — взаимодействие с базой данных
- Pydantic — проверка входящих данных
- Uvicorn — запуск сервера

## Структура проекта

- `main.py` — API и обработчики запросов.
- `database.py` — подключение к базе данных.
- `models.py` — модель финансовой операции.
- `schemas.py` — схемы проверки и ответа API.
- `requirements.txt` — зависимости проекта.

## Установка и запуск

1. Клонировать репозиторий.
2. Создать виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активировать его в Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

4. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустить сервер:

   ```bash
   uvicorn main:app --reload
   ```

6. Открыть документацию API:

   [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## Реализованные API

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/api/transactions` | Создание финансовой операции |
| GET | `/api/transactions` | Получение списка всех операций |
| DELETE | `/api/transactions/{transaction_id}` | Удаление операции по идентификатору |
| GET | `/api/summary` | Получение финансовой сводки |

## Модель финансовой операции

- `id` — уникальный идентификатор операции.
- `type` — тип операции (`income` или `expense`).
- `amount` — сумма операции.
- `category` — категория.
- `date` — дата операции.
- `comment` — комментарий (необязательный).

## Финансовая сводка

API `/api/summary` рассчитывает:

- `income` — общую сумму доходов.
- `expenses` — общую сумму расходов.
- `balance` — текущий баланс (доходы минус расходы).

Финансовые показатели рассчитываются на основе записей, хранящихся в базе данных, поэтому после добавления или удаления операций сводка автоматически обновляется.

## Удаление финансовых операций

Для удаления операции используется запрос:

`DELETE /api/transactions/{transaction_id}`

В качестве параметра передаётся уникальный идентификатор операции.

При успешном удалении API возвращает подтверждение с идентификатором удалённой записи. Если операция с указанным идентификатором не найдена, возвращается ошибка `404 Not Found`.

## База данных

Используется SQLite. Таблица `transactions` создаётся автоматически при запуске приложения.

## Тестирование

Работа API проверяется через Swagger UI (`/docs`). Проверены создание, получение и удаление финансовых операций, а также корректность расчёта финансовой сводки и обработка ошибок при попытке удалить несуществующую операцию.
