# ВедиБюджет — Backend API

Backend-часть мобильного приложения «ВедиБюджет» для учёта личных финансов.

## Технологический стек

- Python
- FastAPI — создание REST API
- SQLite — хранение данных
- SQLAlchemy — взаимодействие с базой данных
- Pydantic — проверка входящих данных
- Uvicorn — запуск сервера

## Структура проекта

- `main.py` — API и обработчики запросов.
- `database.py` — подключение к базе данных.
- `models.py` — модель финансовой операции.
- `schemas.py` — схемы проверки и ответа API.
- `requirements.txt` — зависимости проекта.

## Установка и запуск

1. Клонировать репозиторий.
2. Создать виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активировать его в Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустить сервер:

   ```bash
   uvicorn main:app --reload
   ```

6. Открыть документацию API:

   [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## Реализованные API

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/api/transactions` | Создание финансовой операции |
| GET | `/api/transactions` | Получение списка всех операций |
| PATCH | `/api/transactions/{transaction_id}` | Изменение финансовой операции |
| DELETE | `/api/transactions/{transaction_id}` | Удаление операции по идентификатору |
| GET | `/api/summary` | Получение финансовой сводки |

## Модель финансовой операции

- `id` — уникальный идентификатор операции.
- `type` — тип операции (`income` или `expense`).
- `amount` — сумма операции.
- `category` — категория.
- `date` — дата операции.
- `comment` — комментарий (необязательный).

## Создание финансовых операций

Для создания операции используется запрос:

`POST /api/transactions`

Пример JSON:

```json
{
  "type": "expense",
  "amount": 500,
  "category": "Продукты",
  "date": "2026-11-04",
  "comment": "Покупка продуктов"
}
```

Тип операции может быть `income` (доход) или `expense` (расход). Сумма должна быть больше нуля.

## Изменение финансовых операций

Для изменения существующей операции используется запрос:

`PATCH /api/transactions/{transaction_id}`

В качестве параметра передаётся уникальный идентификатор операции.

Метод PATCH позволяет изменять отдельные поля операции без повторной передачи всех данных.

Доступные для изменения поля:

- `type` — тип операции (`income` или `expense`).
- `amount` — сумма операции.
- `category` — категория.
- `comment` — описание операции.

Пример JSON для изменения суммы, категории и описания:

```json
{
  "amount": 750,
  "category": "Покупки",
  "comment": "Изменённая операция"
}
```

Также можно изменить тип операции:

```json
{
  "type": "income"
}
```

При обновлении сохраняются исходные идентификатор и дата операции. Если операция с указанным идентификатором не найдена, API возвращает ошибку `404 Not Found`.

## Удаление финансовых операций

Для удаления операции используется запрос:

`DELETE /api/transactions/{transaction_id}`

В качестве параметра передаётся уникальный идентификатор операции.

При успешном удалении API возвращает подтверждение с идентификатором удалённой записи. Если операция с указанным идентификатором не найдена, возвращается ошибка `404 Not Found`.

## Финансовая сводка

API `/api/summary` рассчитывает:

- `income` — общую сумму доходов.
- `expenses` — общую сумму расходов.
- `balance` — текущий баланс (доходы минус расходы).

Финансовые показатели рассчитываются на основе записей, хранящихся в базе данных. Поэтому после добавления, изменения или удаления операций сводка автоматически обновляется.

## База данных

Используется SQLite. Таблица `transactions` создаётся автоматически при запуске приложения.

## Тестирование

Работа API проверяется через Swagger UI (`/docs`).

Проверены:

- создание финансовых операций;
- получение списка операций;
- изменение типа, суммы, категории и описания операции;
- удаление финансовых операций;
- корректность пересчёта финансовой сводки после изменения данных;
- обработка ошибок при попытке изменить или удалить несуществующую операцию.
